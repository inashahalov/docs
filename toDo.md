#### 2. Бизнес-метрики — выучить как таблицу умножения
```

```
**Ресурс**: [Mode Analytics SQL Tutorial](https://mode.com/sql-tutorial) — разделы «Advanced», «Business Metrics».

| **Metabase** | Простой интерфейс, быстрый старт | Минимум настройки, максимум результата для портфолио |
